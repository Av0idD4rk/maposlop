# Интерактивная 3D-карта регионов России

Полноэкранная карта на TypeScript и Three.js. Каждый регион — отдельный SVG-контур с объёмом, подсветкой при наведении и выбором по клику.

## Запуск

```bash
npm install
npm run dev
```

## Проверка production-сборки

```bash
npm run build
```

## Структура

- `src/main.ts` — Three.js-сцена, интеракции и навигация по карте.
- `src/style.css` — полноэкранное оформление и элементы управления.
- `public/russia-regions.svg` — векторные контуры регионов.

Сборка, зависимости, скриншоты и скачанные референсы намеренно исключены из Git.
